# About the app

Adventure Guide Forever is a World of Warcraft: Forever addon written in Lua 5.1, with Python tooling
that generates its data and runs its checks. The game cannot run here. What verifies a change is the
repo's own gate: `stylua --check .`, `luacheck .`, `tools/typecheck.sh` against the pinned client
annotations, the generators under `tools/`, and every `tests/*_spec.lua` under LuaJIT, where the specs
stub the client API and load the addon files the TOC lists in order.

Sloppatrol does not read Lua yet, so its census and survey see nothing to propose. That is expected;
the checks below are what make a proposed change verifiable anyway.

## Useful refactors in this tree

- A `UI/` file that repeats a frame, tooltip or settings-page pattern another one already has.
- A branch that recomputes a condition established a few lines above.
- A table built at load time that is only read inside one function.

## Never

- Never edit `Data/` or `Locales/` by hand: `Data/` is generated by the tools in `tools/`, and the
  translations come from `Locales/phrases.txt`.
- Never replace a Blizzard global or hook a secure function a spec does not already hook: the taint
  lint refuses it, and so does the game.
- Never edit `tools/forever_tools/` - vendored byte for byte from forever-core.
- Never launch the game, Battle.net, Lutris or Wine, and never use the network.
- Never leave the working tree with two changes at once: one change, one commit.
