### Fixed

- **Searching the guide is faster.** Typing in the guide's search box folded and ranked every quest title again on each keystroke, taking over a frame to answer; titles now fold once and a title is only ranked when it holds every word searched for, so the results keep up with typing.
- **The first login's quest catalogue builds with less waste.** A quest that hands over nothing which runs out no longer builds and sorts an empty list of expiring items, so the one-off catalogue build at a first login does less work per quest.
