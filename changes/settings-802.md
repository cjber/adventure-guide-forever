### Changed

- **The settings are one page under four headings.** Route, Map, Objective tracker and Interface now sit on a single Adventure Guide page in Settings > AddOns, most-used first, instead of four subpages behind an index of buttons.
- **One tracker switch for the guide's quests.** "Track only the journey's quests" now covers a RestedXP guide too, so the separate RestedXP row is gone.

### Removed

- **The Forever addons page and its hints.** The grey "install Shortest Path Forever", "SkillUp Forever" and "Tweaks Forever" lines in menus and tooltips are gone, along with the setting that switched them.
- **Settings that did not need a row.** "Attach to quest tracker" goes with the tracker's single placement, and "Include dungeons by default" stays at its default of off.
